# Правила версий WINDOW CREATOR PROGRAM

По схеме пользователя версия имеет вид **A.B.C**:

- **A** — крупное обновление самой программы.
- **B** — выпуск с исправлениями ошибок (багфикс).
- **C** — небольшие функции, окна, настройки и другие мелкие дополнения.

Текущая версия: **1.3.1** — исправление разрешения камеры и чёткости вывода OBS.

Для будущего выпуска увеличивается соответствующая часть версии. Если пользователь явно указал номер выпуска, используется именно он.
